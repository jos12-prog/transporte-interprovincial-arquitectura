# Pruebas de concurrencia pendientes

Los escenarios EQ-02 (dos solicitudes simultáneas sobre el mismo asiento) y EQ-03 (aislamiento de acceso entre agencias) siguen siendo obligatorios para el producto. Se difieren a un change posterior porque este esqueleto no incorpora todavía reglas de reserva ni autorización con las que implementarlos.

Esta carpeta no afirma que EQ-02 o EQ-03 estén probados; no contiene simulaciones ni pruebas de negocio provisionales.
